Onde a computação encontra a toxicologia

A toxicologia sempre dependeu de tempo, dinheiro e testes — muitas vezes em modelos animais — para prever se uma substância é segura. A computação não substitui esse processo, mas está mudando o ritmo dele: hoje, a partir da estrutura de uma molécula, já é possível estimar propriedades relevantes antes mesmo de qualquer ensaio experimental.

Este site reúne os materiais das minhas aulas de bioinformática aplicada à toxicologia — do primeiro contato com dados até o cálculo de descritores moleculares usados em modelos preditivos.
